# Symposium poster

- `poster.pdf`, `poster-preview.png`: Chris's version.
- `poster-v2.html`: 36 x 24 in landscape version for the CDSS symposium. Self-contained
  (images inlined; fonts load from Google Fonts). Open in Chrome and print to PDF with
  margins set to none and background graphics on; the page size is set to 36 x 24 in.

Every number on it is dev data from `docs/research/dev-report.md` and its `data/` files.
No blind test pool exists, so none of it is a sealed result.
